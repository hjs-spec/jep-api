# Licensing scope

Original implementation code, implementation documentation, examples and tests
use the MIT license in [LICENSE](LICENSE), except the attributed copies below.
This retains the MIT declaration in the existing deployment metadata.

The `jep-*.schema.json` schema copies and `tests/fixtures/core-v07/` fixtures
retain the JEP Core BSD-3-Clause terms in
[licenses/JEP-CORE-BSD-3-Clause.txt](licenses/JEP-CORE-BSD-3-Clause.txt).
Fixture provenance is recorded beside the fixtures.

Internet-Draft text, excerpts and extracted Code Components retain their
applicable IETF Trust notices and contribution/IPR terms. Third-party dependencies
and separately attributed material retain their own licenses.

Source releases and container images include these notices and license texts.
